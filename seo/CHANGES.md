# SEO change log

Every edit to a page, redirect rule or guard file is logged here (SEO_STRATEGY.md section 2, rules 2 and 10). One row per change, newest first.

- **Baseline** is the page's Google impressions in the 28 days to 4 Oct 2026 (Search Console, `Marketing/state/seo/baseline_2026-10-07/page_month.json`), with the 16-month total in brackets. A restored page shows a 28-day baseline of 0 or a collapsed number because Google saw 404/410 on it, so judge it against the 16-month total.
- The weekly SEO routine compares the 14 and 28 days after the edit with the 28 days before. If impressions fall by more than 30% while the site as a whole did not, the edit is rolled back (title and description first, then body).
- Never delete or redirect a page listed in `seo/protected-urls.txt` (see `CLAUDE.md`).
